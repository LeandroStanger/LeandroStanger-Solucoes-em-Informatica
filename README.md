## Descrição

Site institucional da Leandro Stanger Soluções em Informática, empresa especializada em assistência técnica profissional. O projeto apresenta os serviços oferecidos, com valores e descrições detalhadas, além de facilitar o contato direto via WhatsApp para agendamentos e orçamentos.

## Serviços Oferecidos

### Formatação e Instalação de Sistemas

- **Formatação Standard (Windows)**: Formatação completa do sistema Windows 10/11 com instalação limpa, drivers essenciais e todas as atualizações.
- **Formatação Standard Plus (Windows)**: Formatação do Windows com backup completo dos arquivos pessoais, documentos e configurações.
- **Formatação Standard (Mac OS)**: Formatação completa para computadores Apple com Mac OS, incluindo reinstalação do sistema e configuração inicial.
- **Formatação Standard Plus (Mac OS)**: Formatação do Mac OS com backup completo dos dados, fotos, vídeos e documentos.
- **Formatação Standard (Linux Desktop)**: Formatação com distribuição Linux de sua preferência (Ubuntu, Mint, Fedora, etc.), com drivers e softwares essenciais.
- **Formatação Standard Plus (Linux Desktop)**: Formatação Linux com backup completo dos arquivos, mantendo a estrutura de pastas.
- **Formatação Go**: Instalação do sistema Big Linux otimizado para baixo custo e desempenho, ideal para computadores com recursos limitados.
- **Formatação Go Plus**: Formatação Go com backup completo dos dados, drivers e configurações personalizadas.
- **Formatação Standard Plus Prime**: Pacote para formatação de até 3 computadores, com 60 dias para utilização das demais formatações.
- **Formatação Gamer (Windows)**: Sistema Windows otimizado para jogos com tweaks de desempenho, drivers atualizados e configurações de baixa latência.

### Melhoramento de Desempenho

- **Melhoramento de Desempenho (Turbo)**: Otimização avançada do sistema operacional com desativação de serviços desnecessários, ajustes de registro, gerenciamento de inicialização e muito mais.

### Limpeza e Manutenção

- **Limpeza Plus**: Desmontagem completa, limpeza interna (ventoinhas, dissipadores, fonte) e montagem com aplicação de pasta térmica nova.
- **Limpeza Plus Prime**: Pacote com direito a três limpezas, incluindo descontos em outros serviços e prioridade no atendimento.

### Recuperação de Dados

- Planos flexíveis para recuperação de dados, com orçamento personalizado para volumes acima de 80 GB.

### Configuração e Suporte

- **Configuração de Serviços de E-mail**: Configuração de gerenciadores de clientes de e-mail como Outlook, Windows Mail, Mac Mail e outros.
- **Instrução básica**: Aulas particulares sobre utilização do sistema operacional.

### Criação de Sites

- Desenvolvimento de sites profissionais para prestadores de serviços, clínicas, salões de beleza e outros negócios, com design moderno, compatível com celular, tablet e computador, botão de WhatsApp integrado, formulário de contato, catálogo de produtos e serviços, mapa de localização e alta velocidade.
